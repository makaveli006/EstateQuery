# EstateQuery

Ask about **DarGlobal** development projects and **Wasalt** property listings in Saudi Arabia.

- Answers come only from a snapshot of public pages on darglobal.co.uk and listings on Wasalt.sa, and each answer links to its sources.
- The model button in the message box, next to send, switches model at any time, so you can compare OpenRouter models with Claude on the same question. Each answer shows which model wrote it.
- Listing data: **Source: Wasalt.sa**. Prices and availability change, so check the live listing.
- This is information, not investment advice.
- Your conversations are saved so you can return to them from the sidebar. They are tied to an anonymous cookie in this browser, not to an account, and you can delete any of them from the sidebar menu.
